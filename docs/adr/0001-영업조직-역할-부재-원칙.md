# ADR-0001. 영업 조직 역할을 만들지 않는다

- 날짜: 2026-08-22
- 상태: 채택
- 관련: 명세서 0.4절, 기획서 7-4(역이용 방지), F-CMN-002

## 결정

이해도 데이터 접근 권한을 부여할 수 있는 역할 자체를 만들지 않는다. 본부 영업·마케팅
조직에 대응하는 상수는 `security/Role.java`에 존재하지 않는다 — 누락이 아니라 설계다.

## 근거

권한을 주지 않는 것과 줄 수 있는 대상을 없애는 것은 다르다. 역할이 존재하면 언젠가
"이번만 조회 권한 주자"가 정책 파일 수정으로 가능해진다. 역할이 없으면 코드를 고쳐야
하고, 그것은 PR에 남는다. 통제 지점을 운영에서 코드 리뷰로 옮기는 것이 이 결정의 목적이다.

## 범위

SELLER(창구 판매 직원)와 영업 조직은 다르다. SELLER는 세션을 진행하고 S-05 판정 결과를
보는 주체이므로 유지한다. 차단 대상은 이해도 집계를 받아 타겟팅에 쓸 수 있는 쪽이다.

역할 부재만으로는 부족하다. `rbac_policy.yaml`의 데이터 범위 분리가 실제 차단을 만든다 —
SELLER는 `own_session`, MGR은 `branch`, 집계(`aggregate:*`)는 COMPL만. 역할만 지우고
범위를 나누지 않으면 SELLER 권한으로 대시보드가 열려 같은 구멍이 난다.
