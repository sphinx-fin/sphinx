# ADR-002. 적색 오버라이드 승인자는 지점 관리자(MGR)를 유지한다

- **상태**: Accepted (한계 인지)
- **일자**: 2026-08-22
- **결정자**: 정세현 / 협의: 강희진
- **관련**: 기획서 4장·7-5, 기능명세서 F-GTE-002

## 맥락

적색(오해 탐지 또는 적합성 모순) 상태에서 판매를 진행하려면 승인이 필요하다. 기획서 보완본은
"적색에서 진행하려면 관리자 승인과 사유 기록을 강제한다"로 제출됐고, 여기서 관리자는 지점
관리자(MGR)를 가리킨다.

그런데 지점 관리자는 영업 라인에 속하고 판매 목표를 갖는다. **승인자가 판매 인센티브를 갖는
구조는 게이트를 약화시킨다.** 승인 권한을 컴플라이언스 또는 별도 심사 조직으로 옮기는 안을
검토했다.

## 결정

**MVP에서는 MGR 승인을 유지한다.**

근거는 세 가지다.

1. **기획서 보완본이 이미 제출됐다.** 코드가 제출 문서와 다르면 그 불일치 자체가 더 큰 리스크다.
2. **현행 실무와 정합성이 있다.** 적합성 예외 승인 등 창구 예외 처리는 지점 관리자 결재 구조가
   일반적이라, 도입 현실성 측면에서 방어 가능하다.
3. **견제 장치가 이미 설계에 있다.** 오버라이드 시 컴플라이언스 자동 통보(F-GTE-002), 사유 기록
   필수(최소 30자, API·UI 이중 검증), `evidence` 계층의 불변 기록, 오버라이드 건 별도 집계.

## 인지하는 한계

승인자가 판매 인센티브를 갖는다는 구조적 약점은 해소되지 않았다. 오버라이드가 관행화되면
게이트가 형해화될 수 있다.

**완화 장치**: 오버라이드 비율을 대시보드 상시 지표로 노출하고, 지점·판매자 단위 이상치를
컴플라이언스에 넘긴다. 승인 자체가 기록으로 남아 사후 검증이 가능하다.

**다음 단계(MVP 범위 외)**: 승인 권한을 영업 라인 밖의 심사 조직으로 분리. 적색 판매의 승인
주체와 판매 실적 책임 주체를 완전히 분리하는 것이 최종 형태다.

## 심사 질의 대비

> "적색인데 지점장이 승인하면 결국 팔리는 것 아닌가?"

승인 권한의 심사 조직 분리가 다음 단계이며, 현재 구조에서도 (i) 컴플라이언스 실시간 통보,
(ii) 사유가 포함된 불변 기록, (iii) 오버라이드 비율 지표로 견제한다. 무엇보다 **지금은 적색이라는
판정 자체가 존재하지 않는다** — 승인 기록이 남는 것만으로도 현행 대비 통제 수준이 올라간다.
