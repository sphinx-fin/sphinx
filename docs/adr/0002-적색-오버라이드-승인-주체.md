# ADR-0002. 적색 오버라이드 승인은 MGR이 유지한다 (한계 인지)

- 날짜: 2026-08-22
- 상태: 채택 (한계 있음, 다음 단계 예정)
- 관련: F-GTE-002, 기획서 보완본, F-CMN-002

## 결정

적색 판정 오버라이드 승인 권한을 지점 관리자(MGR)에 둔다. `rbac_policy.yaml`의
`override:approve: { roles: [MGR], scope: branch }`.

## 알려진 한계

지점 관리자는 영업 라인이고 판매 목표를 갖는다. 그 사람이 적색 판매를 승인하는 구조는
견제 관점에서 약한 고리다. 승인 권한을 심사 조직으로 분리하는 것이 구조적으로 더 옳다.

## 그럼에도 유지하는 이유

기획서 보완본이 "관리자 승인과 사유 기록을 강제한다"로 이미 제출됐다. 코드가 제출된
기획서와 다른 것이 이 한계보다 큰 문제다.

## 현재의 견제 장치

- COMPL 자동 통보 — 오버라이드 발생 시 준법감시에 실시간 전달 (설계에 이미 포함)
- 사유 30자 미만 거부 — API에서 강제 (`OverrideController`)
- 불변 기록 — `evidence/` 해시 체인에 append, 사후 변조 불가
- 요청자 ≠ 승인자

## 다음 단계

승인 권한을 심사 조직으로 분리한다. 심사 질의 시 답변: "승인 권한을 심사 조직으로
분리하는 것이 다음 단계이며, 현재는 컴플라이언스 실시간 통보와 불변 기록으로 견제한다."
