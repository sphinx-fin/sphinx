# F-CMN-003 채점 성능 평가

모델 출력 70건 · 라벨러 2명 (강희진, 정세현)

## 1. 평가자 간 일치도 — 이것이 상한이다

사람도 안 맞는 항목에서 모델이 사람과 맞기를 기대할 수 없다. 모델 점수는
아래 값과 **나란히** 읽어야 의미가 있다.

  강희진 ↔ 정세현                    QWK +0.769 · linear +0.708 · 일치율 72.9% · n=70

  혼동행렬 (행=정답 · 열=예측)

    U1       7     4     0     0

    U4       1     2     0    19

## 2. 모델 vs 각 라벨러 — 상한과 **같은 표본**이다

1절의 상한과 이 값들만 직접 비교할 수 있다. 3절은 표본이 다르다(그쪽 설명 참조).

  모델 ↔ 강희진                     QWK +0.706 · linear +0.644 · 일치율 68.6% · n=70
  모델 ↔ 정세현                     QWK +0.682 · linear +0.618 · 일치율 67.1% · n=70

## 3. 모델 vs 합의 — 두 사람이 같은 등급을 준 항목만

  합의 51건 · 불일치 제외 19건

  ❗**이 값을 1절 상한과 직접 비교하지 않는다.** 두 사람이 갈린 항목이 빠진
  집합이라 남은 것은 사람도 쉽게 합의한 문제들이고, 모델은 그만큼 쉬운 시험을
  본 것이 된다. 상한과 나란히 놓을 값은 2절이다(같은 표본).

  모델 ↔ 합의                      QWK +0.795 · linear +0.747 · 일치율 78.4% · n=51

  혼동행렬 (행=정답 · 열=예측)

## 4. 미탐율 — U4(오해)를 U1·U2 로 읽은 비율

❗카파와 **따로** 본다. 표본에서 U4 가 소수면 카파가 높은 채로 미탐율이
나쁠 수 있고, 그 조합이 이 시스템에서 제일 나쁜 상태다.

  미탐 4/19 = 21.1%   (U4 를 U4 로 읽은 것 15건)

  게이트 결과로 가른다 — 둘 다 오해를 못 잡은 것이지만 대가가 다르다.
    U4 → U1       0건   게이트가 GREEN 까지 갈 수 있다 (R-06)
    U4 → U2·U3    4건   RED 가 YELLOW 로 내려앉는다 (R-04)

  정답 분포 {'U1': 7, 'U2': 12, 'U3': 13, 'U4': 19}
  모델 분포 {'U1': 11, 'U2': 13, 'U3': 11, 'U4': 16}

## 5. 목표선

  모델 QWK +0.795 vs 목표 +0.750 → **달성**   (3절 · 합의 51건 기준)

  ### 상한과의 거리 — 같은 표본(2절)으로만 잰다

    상한  강희진 ↔ 정세현   +0.769
    모델 ↔ 강희진   +0.706  (상한의 92%)
    모델 ↔ 정세현   +0.682  (상한의 89%)

  가이드라인을 고쳐야 한다(사람끼리 갈리는 자리가 곧 천장이다).
